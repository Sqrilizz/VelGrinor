# Building from Source

VelGrinor is written in Rust with a React/Tauri frontend. Here's how to build it yourself.

## Prerequisites

### Required

- **Rust** (latest stable) - [Install via rustup](https://rustup.rs)
- **Node.js 20+** with npm - For the frontend
- **Git** - To clone the repository

### macOS

```bash
# Install Xcode command line tools
xcode-select --install

# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install Node.js 20+ from https://nodejs.org
```

### Linux

```bash
# Install system dependencies (Ubuntu/Debian)
sudo apt update
sudo apt install -y libwebkit2gtk-4.1-dev build-essential curl wget file libssl-dev libayatana-appindicator3-dev librsvg2-dev

# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install Node.js 20+ from https://nodejs.org
```

### Windows

1. Install [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
2. Install [Rust](https://rustup.rs)
3. Install [Node.js 20+](https://nodejs.org)

## Clone the Repository

```bash
git clone https://github.com/Sqrilizz/VelGrinor.git velgrinor
cd velgrinor
```

## Build the CLI

The CLI/core library is in the `launcher/` directory:

```bash
# Development build (fast, unoptimized)
cargo build -p velgrinor

# Release build (slow, optimized)
cargo build -p velgrinor --release

# Run the CLI
cargo run -p velgrinor -- --help
```

## Build the Desktop App

The desktop app is in the `desktop/` directory:

```bash
cd desktop

# Install frontend dependencies
npm install

# Development mode (with hot reload)
npm run tauri:dev

# Build for production
npm run tauri:build
```

The built app will be in `desktop/src-tauri/target/release/bundle/`.

## Build Profiles

| Profile | Command | Build Time | Use Case |
|---------|---------|------------|----------|
| `dev` | `cargo build` | ~10s | Development, debugging |
| `dev-release` | `cargo build --profile dev-release` | ~30s | Quick testing |
| `release` | `cargo build --release` | ~3-5min | Production builds |

## Environment Variables

Create a `.env` file in the repository root:

```bash
# Required for Microsoft authentication
MICROSOFT_CLIENT_ID=your-client-id

# Optional: CurseForge API key
VELGRINOR_CURSEFORGE_API_KEY=your-api-key
```

See `.env.example` for all available options.

## Troubleshooting

### Rust compilation errors

Make sure you have the latest Rust:

```bash
rustup update stable
```

### Tauri build fails

Ensure you have all system dependencies installed. On macOS:

```bash
xcode-select --install
```

### Frontend dependency issues

Clear and reinstall:

```bash
cd desktop
rm -rf node_modules
npm install
```
